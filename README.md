# Ministral

SaaS multi-tenant de gestão de ministérios para igrejas.

## Stack Tecnológica
- **Frontend**: React 18, TypeScript, Vite, TailwindCSS
- **Estado/Dados**: Zustand, TanStack Query
- **Backend/DB**: Supabase (PostgreSQL, Edge Functions em Deno)
- **Deploy**: Vercel
- **IA**: Gemini API (@google/genai)
- **Pagamentos**: Stripe
- **Notificações**: Web Push + WhatsApp (Evolution API)
